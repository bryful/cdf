# cdf

cdf.exe はコンソールベースのフォルダ選択ツールです。

##概要
- ターミナル上でディレクトリを視覚的に選択するための小さなユーティリティ（Windows 専用）。

##主な操作
- ↑ ↓ : 項目選択
- Enter : フォルダを開く
- Space / Q : 選択（確定）
- D : ドライブ選択（フォルダ選択モード時）
- Esc : 戻る／終了

##実行例
- cdf.exe
- cdf.exe C:\\path\\to\\start\\directory

##注意
- Windows 環境専用（コンソール API を使用）。
- 実行時の出力や挙動はバイナリに依存するため、実行後に動作を確認してください。
